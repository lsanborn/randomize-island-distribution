# randomize-island-distribution
This script provides the methodology used in Chapter 5.3.2 of L. Sanborn's doctoral thesis, "Null modeling of island distribution", dated 12 November 2025. 

This script randomly generates synthetic islands, given the X and Y position of an atoll reef flat (supplied in 10 m x 10 m grid resolution). This script was used to test whether the planform distribution of island landmass correlates with reef flat area. 100 synthetic simulations were performed for each atoll included in the study, and results were aggregated. Full methodology is described in the thesis, found here: https://hdl.handle.net/1721.1/165508
